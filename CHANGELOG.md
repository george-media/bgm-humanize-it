# Changelog

Changes are grouped by date. There is no numbered release series yet; pin a repository commit when you need a reproducible installation.

## 2026-10-14

- Added BGM Humanize It for scoped drafting and editing with factual and voice fidelity.
- Added BGM AI Check for contextual editorial review with quoted evidence, no authorship verdicts and an authorised editing handoff to BGM Humanize It.
- Recorded structural checks, behavioural examples, independent reviews and substantive Claude reviews for both packages.
- Added repository documentation for installation, usage, research limits, contribution and licensing, plus GitHub issue and pull-request templates.

Local enable/disable settings are user configuration, not part of the distributed packages. Installing these skills does not change the legacy Humanize or AI-Check packages.
